# Оракул

**Локальный ИИ для ПК и телефона. Без интернета. Без облаков. Без подписок.**

EXE для Windows · APK для Android · работает на вашем устройстве

Код: [standimaoff-oss/aiarsenal](https://github.com/standimaoff-oss/aiarsenal) → папка `app/`. Релизы приложения: пре-релизы с тегами `app-v*`; релизы модели (Заход 2): теги `model-v*`.

</div>

---

Оракул — это ИИ-ассистент, который **живёт на вашем устройстве**. Модель (~0,5 млрд параметров, русский и английский) работает полностью локально: вопросы, чаты и файлы никуда не отправляются. Когда нужен свежий факт — вы видите, что именно Оракул ищет и что читает: нажмите на шаг, чтобы раскрыть полный список сайтов.

## Что уже работает

**Заход 2 (в работе, v0.2.0-dev.0):** локальная модель подключена к приложению: кнопка «Скачать модель (≈400 МБ)» в «Настройки → ИИ и модель» (веса Qwen2.5-0.5B-Instruct Q4_K_M с Hugging Face, кэш OPFS, далее — полностью офлайн), переключатель «Реальная локальная модель», потоковый ответ, стоп-кнопка, откат на демо-движок при ошибке. Проверить в деле можно на устройстве с ~500 МБ свободного места.

**Заход 1 ✅**

- 💬 **Чаты** — в стиле самых популярных ИИ-чатов: слева список, группировка по датам, поиск по истории, всё хранится локально.
- 🔍 **Агентный трейс** — видны все действия агента: «Поиск: 15 сайтов» → по клику раскрывается полный список; «Чтение: 4 страницы», «Сверяю факты», «Черновик ответа».
- 🎚️ **Уровни размышления** — от **Мгновенно** (только суть, ~1 с) до **Ультра** (план → поиск → чтение → черновик → самопроверка, ~5–10 с).
- 👤 **Профиль** — локальный, на этом устройстве: имя, аватар, статистика, экспорт чатов в JSON.
- 🔄 **Самообновление** — приложение и модель обновляются отдельно, через GitHub Releases (проверка версии в один клик; тихая замена на EXE, системный диалог установки на Android).
- 🌗 **Тема** — тёмная/светлая/системная, 4 акцента, три размера текста.
- ⌨️ **Горячие клавиши** — `/` фокус на ввод, `Ctrl+K` новый чат, `Ctrl+B` сайдбар, `Esc` закрыть панели.

Сейчас агентный ход работы показан на демо-данных — живой веб-поиск подключается в Заходе 3 (см. [ROADMAP](docs/ROADMAP.md)).

## Быстрый старт (разработка)

```sh
git clone https://github.com/standimaoff-oss/aiarsenal.git
cd aiarsenal/app
npm ci
npm run dev      # http://localhost:5173
```

Сборка веба: `npm run build` → `app/dist/`. CI: `.github/workflows/oracle-ci.yml` (пути `app/**`).

Сборка **EXE** (установщик Windows, NSIS) и **APK** (Android) — через GitHub Actions (Заход 4); локально нужны Rust + Android SDK. См. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Принципы

1. **Сначала офлайн.** Всё основное работает без интернета. Сеть нужна только для веб-поиска и обновлений — и только с вашего ведома.
2. **Прозрачность.** Агент не «думает молча»: каждый поиск и каждая прочитанная страница видны.
3. **Минимум зависимостей.** Веб-интерфейс — без единой runtime-зависимости; обёртка — Tauri v2 (Rust + системный WebView), не Electron.
4. **Данные — ваши.** Никакой телеметрии и аккаунтов. Экспорт и очистка истории — в настройках.

## Дорожная карта

| Заход | Что появится |
|---|---|
| **1** ✅ | Каркас, минималистичный UI, чат, трейс агента, уровни размышления, профиль, обновление из GitHub |
| **2** 🔧 | Локальная модель подключена (скачивание, OPFS, офлайн-инференс, стоп); осталось проверить на телефоне и ПК |
| **2** | Настоящая локальная модель: GGUF-веса из GitHub Releases, стриминг, офлайн-режим, SQLite |
| **3** | Живые инструменты: веб-поиск без API-ключей, чтение страниц, калькулятор, локальная база знаний (RAG) для офлайна |
| **4** | Сборка EXE + APK в CI, самоустановка обновлений, раздельные версии приложения и модели |
| **5** | «Своё ИИ»: конвейер дообучения (LoRA) открытого ядра под наш стиль; при бюджете — претрейн 0.3B с нуля |

## Структура

```
index.html              — каркас интерфейса
src/js/agent.js         — агентный движок (Заход 1: демо; Заход 2: локальная модель)
src/js/main.js          — UI-оркестрация
src/js/store.js         — состояние и localStorage (чаты, настройки)
src/css/app.css         — дизайн-система «минимализм»
src-tauri/              — обёртка Tauri v2 (EXE / APK)
docs/                   — архитектура, модель, дорожная карта
```
