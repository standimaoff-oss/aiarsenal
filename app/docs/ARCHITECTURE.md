# Архитектура Оракула

## Слои

```
┌─────────────────────────────────────────────┐
│ UI (web, без runtime-зависимостей)          │  index.html · src/css · src/js/main.js
│ чаты · трейс агента · уровни усилий · темы  │
├─────────────────────────────────────────────┤
│ Агентное ядро (src/js/agent.js)             │
│ планировщик → инструменты → самопроверка    │
├───────────────────┬─────────────────────────┤
│ Инференс (Заход 2)│ Инструменты (Заход 3)   │
│ wllama/llama.cpp  │ поиск · чтение · кальк. │
│ GGUF, офлайн      │ RAG по локальной базе   │
├───────────────────┴─────────────────────────┤
│ Хранилище: localStorage → SQLite (Tauri)    │
├─────────────────────────────────────────────┤
│ Оболочка: Tauri v2 (Windows EXE / Android)  │
└─────────────────────────────────────────────┘
```

## Почему Tauri, а не Electron и не Flutter
- **Размер**: установщик ~5–10 МБ против ~150 МБ у Electron. Требование — «без больших зависимостей».
- **Одна кодовая база** → EXE и APK; UI — обычные веб-технологии.
- **Доступ к системе**: файловая система, уведомления, автозапуск, автообновление (tauri-plugin-updater).
- Flutter оставался запасным вариантом (зрелее мобильный UI), но тянет Dart-окружение и больше по размеру.

## Модель
См. [MODEL.md](MODEL.md). Ключевое: приложение никогда не зависит от весов в сборке — модель скачивается отдельно из релизов (`model-v*`), приложение (`app-v*`) можно обновлять независимо.

## Обновления
- **Приложение**: GitHub Releases. В приложении кнопка «Проверить обновления» → GitHub API → сравнение semver → приложение открывает страницу релиза (Заход 4: тихая установка через Tauri updater на Windows; на Android — системный диалог).
- **Модель**: тот же механизм, теги `model-v*`; атомарная замена GGUF + проверка контрольной суммы SHA-256 (публикуется в релизе).
- CSP приложения (`tauri.conf.json`) разрешает исходящие запросы только к `api.github.com` — кроме явно включённого веб-поиска (Заход 3), всё остальное остаётся на устройстве.

## Приватность
- Чаты, профиль, настройки — в локальном хранилище устройства. Никакой телеметрии, аккаунтов и аналитики.
- Экспорт (`oracle-chats.json`) и полная очистка — в «Настройки → Данные».

## Сборка EXE/APK (Заход 4)
- Windows: runner `windows-latest`, `tauri-apps/tauri-action`, NSIS-установщик, подпись (при наличии сертификата), релиз `app-vX.Y.Z`.
- Android: `tauri android build --apk` на `ubuntu-latest` (JDK + Android SDK в раннере), APK прикладывается в релиз.
- CI на push в `main`: только веб-сборка и линт (см. `.github/workflows/ci.yml`) — быстрые проверки без релиза.
