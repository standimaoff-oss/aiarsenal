# Дорожная карта Оракула

Цель: локальный ИИ для ПК (EXE) и телефона (APK) — офлайн, с агентным интерфейсом и уровнями размышления, ядром от ~0,3 млрд параметров.

## Заход 1 — каркас и лицо ✅
- Минималистичный интерфейс в духе популярных ИИ-чатов: сайдбар (чаты / профиль / настройки), лента, композер.
- Агентный трейс: раскрывающиеся шаги «Поиск → Чтение → Сверка → Черновик → Проверка», список источников по клику.
- Уровни размышления: Мгновенно / Быстро / Стандарт / Глубоко / Ультра (≈1 / 2 / 4 / 7 / 10 с).
- Профиль, темы (тёмная/светлая/системная), акценты, размер текста, экспорт чатов, проверка обновлений через GitHub API.
- Иконка, репозиторий, CI для веб-сборки.

## Заход 2 — живой локальный ИИ 🔧 (в работе, v0.2.0-dev.0)
- Ядро: **Qwen2.5-0.5B-Instruct** в GGUF (Q4_K_M, ≈400 МБ) — лучший маленький русский+английский вариант; запасные: SmolLM2-360M, Llama-3.2-1B.
- Исполнение: `@wllama/wllama` (MIT, llama.cpp → WebAssembly), локальный `public/wasm/wllama.wasm` (10 МБ, в git не хранится), `setCompat(null)` — никакого CDN.
- Веса: скачивание по кнопке из Hugging Face (официальный GGUF Qwen) → кэш OPFS на устройстве → офлайн навсегда. Зеркало в релизе GitHub `model-v*` — опционально.
- Уровни усилий = реальные рычаги: температура/top-p/`max_tokens` (Мгновенно — жадный выбор, 96 токенов; Ультра — 900).
- Стоп-кнопка: прерывание генерации через `abortSignal`.
- Откат: если модель не загрузилась/упала — честный откат на демо-движок с пояснением.
- Осталось в Заходе 2: прогон на реальном телефоне и ПК (скорость, память), SQLite вместо localStorage, self-consistency для «Глубоко/Ультра».

## Заход 3 — агентность
- Веб-поиск без ключей: DuckDuckGo HTML / SearXNG; парсинг, топ-N (N по уровню усилий).
- Чтение страниц: fetch + очистка от меню/скриптов, выжимка основного текста; полный список источников — в трейсе.
- Офлайн: локальный RAG — индекс встроенной мини-базы знаний (ru.wikipedia-экспорт, справочники), BM25; честный ответ «нет сети» там, где нужно живое.
- Калькулятор (точный), дата/время, позже — python-песочница (только офлайн, без сети).

## Заход 4 — упаковка и самообновление
- CI: Tauri build на `windows-latest` → NSIS-установщик; `tauri android build` → подписанный APK; релиз `app-v*` в GitHub Releases.
- Самообновление: Tauri updater (Windows — тихая замена, подпись релиза); Android — скачивание APK и системный диалог установки (так устроена ОС).
- Раздельные версии: приложение (`app-v*`) и модель (`model-v*`); «Настройки → Обновления» показывает обе.
- Иконки всех размеров, подпись, «О приложении».

## Заход 5 — «своё ИИ» (лёгкий гибрид, без тяжёлого претрейна)
- **LoRA/SFT-дообучение** открытого ядра на наших данных (русские инструкции, стиль Оракула, формат трейса: план → поиск → ответ). Датасет: 5–20 тыс. примеров, сбор из разрешённых источников + ручная курировка.
- Публикация адаптера (`model-v*`) — приложение подхватывает как обычное обновление модели.
- **Претрейн 0.3B с нуля — только по отдельному решению с бюджетом**: ~6–15 млрд токенов (Chinchilla), 20–60 GPU-дней A100-класса, сотни–тысячи долларов на облаке; код и конфиги (`training/`) будут готовы, чтобы запуск был «одна команда».
- Честный потолок: 0.3–0.5B не заменит большие модели; сила Оракула — локальность + инструменты + прозрачность.
